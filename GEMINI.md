Design the website as if it were a vertical Instagram Story that users scroll. Every screen should fit within a mobile viewport. Use large photography, very little text, and one idea per screen. Avoid desktop landing page conventions. The mobile version should feel native and complete even if the desktop version never existed.


Mobile-first. Assume 90% of visitors arrive from Instagram on a smartphone. Design for a 390px-wide screen before designing desktop. Desktop is secondary.


Avoid all startup, SaaS, Apple, organic food, and AI-generated website patterns. The website should feel like a personal notebook from a real farmer. Use short sentences. Use asymmetrical layouts. Avoid feature cards. Avoid generic marketing language. Show evidence instead of claims. Every section should feel like a discovery rather than a sales pitch. Visitors should feel they found a real family farm, not a brand agency project.
