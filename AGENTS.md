# Fourth Cow Instructions

This repository lives at
`/home/ubuntu/workspace/flonestplatform/client-public-sites/fourth-cow/`.
It is a standalone public client website.

## Boundary

Keep this repo independent from Flonest platform code. Do not move shared
platform, Android, Telegram, attendance, or Vyapar bridge work into this repo.
Use it only for the Fourth Cow public website and directly related assets.

## Commands

Use the scripts in `package.json`:

```bash
npm run dev
npm run build
npm run lint
npm run preview
```

Cross-repo workspace organization lives in
`/home/ubuntu/workspace/flonestplatform/AGENTS.md`.
